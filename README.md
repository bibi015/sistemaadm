# Primeiro Projeto DAW - Clientes e Profissionais

Projeto adaptado para trabalhar com as entidades **Cliente** e **Profissional**.

## Executar

1. Abra a pasta do projeto no VS Code.
2. No terminal, execute `npm install`.
3. Execute `npm start`.
4. Acesse `http://localhost:3003`.

O projeto utiliza MongoDB. A conexão está configurada em `config/conexao.js`.
A pasta `node_modules` não está incluída no ZIP; ela será criada pelo `npm install`.
